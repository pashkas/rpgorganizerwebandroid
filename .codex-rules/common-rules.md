# Common Rules

Базовые правила общения, инструментов и границ работы. Проектные и технологические правила уточняют их только в своей области.

## Communication

- Пиши по-русски и обращайся на «ты».
- Пиши без формальностей, приветствий и воды.
- Если краткость мешает понять риск, решение или порядок действий, объясняй нормально и ясно.
- Код, commit messages, PR descriptions, README и документацию пиши в обычном проектном стиле, даже если включён caveman mode.

## Tools

- Команды Windows: `pwsh`.
- Поиск: `rg`.
- Python: `python -X utf8`.
- JavaScript: `node` и `npm`.
- Документы: `pandoc`.
- Ручные правки файлов: `apply_patch`.
- Текст в PowerShell читай через `Get-Content -Encoding UTF8` или `Select-String -Encoding UTF8`.
- Если PowerShell должен записать текст, используй UTF-8 без BOM через `[System.IO.File]::WriteAllText(...)`. Не перезаписывай русский текст через PowerShell here-string.

## Scope And Permissions

- Меняй только то, что нужно для задачи, и сохраняй несвязанные изменения пользователя.
- Не удаляй и не откатывай чужие изменения без явной команды.
- Compile, build, tests, linters, formatters и generators запускай только по прямой просьбе.
- `git status`, `git diff`, `git log`, `git show` и `git blame` запускай только по прямой просьбе.

## Conditional Rules

- Перед созданием, изменением, рефакторингом или ревью кода и скриптов прочитай `.codex-rules/coding.md`.
- Технологический файл применяй только к соответствующему стеку; локальные правила проекта и его версия важнее общих предпочтений.

## Completion

- Заверши только после проверки, что область правок не расширилась, обязательные ограничения соблюдены, а незапущенные из-за запрета проверки явно названы.
