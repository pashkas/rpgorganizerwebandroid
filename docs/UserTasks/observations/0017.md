# index.html настроен с lang="ru" и meta google notranslate для предотвращения предложений перевода в Chrome

## Суть
В index.html установлен `lang="ru"` и добавлен `<meta name="google" content="notranslate">` для предотвращения автоматических предложений перевода страницы в браузере Chrome для русскоязычного проекта.

## Где в коде
- `src/index.html:2` — `<html lang="ru">`
- `src/index.html:5` — `<meta name="google" content="notranslate" />`
