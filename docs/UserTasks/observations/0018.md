# ОП скрыты из интерфейса при isPerkPointsEnable=true

## Суть
Badges с {{pers.OP}} показываются только при !isPerkPointsEnable (в task-detail и pers-list компонентах).

## Исправлено
ОП показываются в интерфейсе при isPerkPointsEnable=true, скрыты при false. Условия в task-detail, pers-list и characteristic-details компонентах обновлены.
